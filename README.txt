# Torvia Travels Website

A static, mobile-friendly tourism/cab website for Torvia Travels.

## Files
- index.html — website structure/content
- style.css — design and responsive layout
- script.js — WhatsApp booking, call buttons, menu and form logic

## Contact configured
- Phone / WhatsApp: 9008522092

## Run locally
Open `index.html` in a browser.

For a local server, from this folder run:
python3 -m http.server 8000

Then open:
http://localhost:8000

## Deploy free
Recommended: Cloudflare Pages.
1. Create a GitHub repository and upload the 3 website files.
2. In Cloudflare Pages, connect the repository.
3. Framework preset: None.
4. Build command: leave blank.
5. Output directory: `/` (or the repository root).
6. Deploy.

## Before publishing
Replace the placeholder background images with your own Torvia/Coorg photographs if available. Update service wording, exact operating areas, and any pricing only after confirming them.
