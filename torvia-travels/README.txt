# Torvia Travels Website

A static, mobile-friendly tourism/cab website for Torvia Travels, Madikeri (Kodagu).

## Files
- index.html   website structure and content
- style.css    design and responsive layout
- script.js    WhatsApp booking, cab selection, Coorg stop picker, call buttons, menu
- img/         all images used on the site (local files, no external image links)
- tools/       optional Python scripts that generated the cab and destination artwork

## What changed in this version
1. Hero background is now a local Coorg coffee estate illustration (img/hero-coorg-coffee.svg)
   instead of a remote stock photo link. No image on the site loads from another website.
2. New "Which cab do you need?" section with four vehicles the customer can tap:
   4 seater hatchback, 5 seater sedan, Innova / Crysta, and 12 to 14 seater Tempo Traveller.
   The choice is filled into the booking form and included in the WhatsApp message.
3. New "Top places in Coorg" section with six destination cards. Tapping a place adds it to
   the trip, shows it as a chip in the booking form, and sends it in the WhatsApp message.
4. The sticky floating button and the WhatsApp buttons now use the real WhatsApp logo
   (img/whatsapp.svg, the file you supplied).
5. Coorg detail throughout: coffee cherry red accent, estate illustration in the tours
   section, distance strip for Mysuru / Bengaluru / Mangaluru / Kannur, and copy that names
   real Kodagu routes and stops.

## Run locally
Open index.html in a browser, or from this folder run:
python3 -m http.server 8000
Then open http://localhost:8000

## About the images
Every image is an SVG illustration in the img/ folder. SVG files are plain text, so colours
can be edited in any code editor. If you later get real photographs of your cars and of
Coorg, replace them like this:

- Hero: put your photo in img/ and change the url() in the .hero rule in style.css.
- Tours strip: same, in the .tour-image rule.
- Cabs: replace the four src values in the fleet section of index.html
  (photograph each vehicle side-on against a plain background for a consistent look).
- Places: replace the six src values in the places section of index.html.
  Use photos you own or have licensed. Keep the alt text updated.

The artwork was generated by the scripts in tools/. Run them from the site folder
(python3 tools/build_cabs.py) if you want to regenerate after changing colours.

## Before publishing
- Check the distances and drive information. The site says "approximate", but confirm
  the numbers for Mysuru, Bengaluru, Mangaluru, Kannur and each sightseeing stop.
- Confirm the vehicle list matches what you can actually supply, including seat counts.
- Confirm Mandalpatti wording, since the final stretch normally needs a local jeep.
- Add pricing only after you have fixed rates.

## Deploy free
Recommended: Cloudflare Pages.
1. Create a GitHub repository and upload index.html, style.css, script.js and the whole
   img/ folder. The img/ folder must be uploaded or the images will not appear.
2. In Cloudflare Pages, connect the repository.
3. Framework preset: None.
4. Build command: leave blank.
5. Output directory: / (repository root).
6. Deploy.
